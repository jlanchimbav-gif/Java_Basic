# Java Basic

Repositorio de ejercicios y ejemplos básicos en Java.

## Estructura del proyecto

- `basic/` - Clases de introducción a conceptos básicos de Java como tipos de datos, operadores, cadenas y variables.
- `ExerciciesBasic/` - Ejercicios relacionados con los fundamentos básicos y condicionales.
- `Functions/` - Ejemplos y ejercicios de funciones/metodos en Java.
- `loops/` - Ejercicios con bucles (`for`, `while`, etc.).
- `structures/` - Ejemplos y ejercicios con estructuras de datos como arreglos, listas, mapas y conjuntos.
- `lib/` - Carpeta reservada para librerías externas si se requieren.

## Cómo compilar y ejecutar

Desde la raíz del repositorio, usa la terminal y ejecuta:

```powershell
javac basic\HelloWord.java
java basic.HelloWord
```

Para compilar múltiples archivos a la vez puedes usar:

```powershell
javac basic\*.java ExerciciesBasic\*.java Functions\*.java loops\*.java structures\*.java
```

Y ejecutar una clase específica indicándola con su nombre de paquete completo. Por ejemplo:

```powershell
java Functions.Functions
```

## Recomendaciones

- Abre los archivos `.java` en tu editor para revisar cada ejercicio.
- Modifica y prueba los ejemplos para practicar los conceptos.
- Usa clases separadas para explorar variables, condicionales, bucles y estructuras de datos.

## Notas

Este repositorio es ideal para aprender y reforzar los fundamentos de la programación en Java.
